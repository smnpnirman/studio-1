# **App Name**: Rural Escapes

## Core Features:

- Facebook Authentication: Allow users to sign up and log in using their Facebook accounts for easy access and social connection.
- Farm Visit Browser: Enable browsing a directory of available farms and experiences with search, filtering, and detailed farm profiles.
- Booking and Scheduling: Provide a booking system to reserve farm visits, scheduling and managing bookings.
- Course Catalog: Offer online courses related to farming, agriculture, and rural living with enrollment capabilities.
- Personalized Schedule: Display a schedule with all of the bookings the user has made and display it on their user page.

## Style Guidelines:

- Primary color: Earthy green (#8FBC8F) to reflect the natural, farm setting.
- Background color: Desaturated light green (#E0EEE0) for a calm and inviting feel.
- Accent color: Brown (#A0522D) used for headers and certain buttons.
- Font pairing: 'Alegreya' serif for headlines and 'PT Sans' sans-serif for body text to create a balance of elegance and readability.
- Use rustic, nature-themed icons such as leaves, tractors, animals.
- Design a layout that emphasizes readability and showcases beautiful photography of farms and rural scenes.
- Incorporate subtle animations and transitions to enhance the user experience, such as smooth scrolling and image fades.
